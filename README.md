# io.roura.renewdtv.legal

Self-hosted legal documents for **RenewdTV** (RouraIndustries), served via GitHub Pages.

- `index.html` — landing page
- `terms.html` — Terms and Conditions (effective 2026-07-22)
- `privacy.html` — Privacy Policy (effective 2026-07-22)

The app's `LegalLinks` points at the published Pages URLs. Amending a policy = edit the HTML, bump the "Last updated" date, push. Pages redeploys automatically.

Pages setup: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
